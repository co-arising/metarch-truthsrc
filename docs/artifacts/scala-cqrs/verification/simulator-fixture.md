# 业务模拟器与外部证据夹具

类别：`simulator-fixture`。本页属于版本化产物说明目录；源码名称、包位置和运行保证按下面的适用变体解释。

## 职责

模拟外部TA或账本提供可重复业务观察和故障场景，不是真实外部集成或生产认证。

## 输入与人工信息

行为、幂等键、结果序列、故障和持久WAL合同由测试/业务需求定义，不从页面随机编造成功。

## 生产与所有权

- `bank-p23`：`PersistentMockTACore` 与 `Journal` 是银行手写 mock/WAL 实现，提供有限外部模拟，不是真实 TA 集成；源码检查不等于行为验证。
- `js-run-all-strict`：旧 strict-contract 链的 `emit-strict-host` 生成受绑定约束的 phase/runtime host 夹具支持代码，不生成银行 mock/WAL，也不供应通用运行库。
- 生成的夹具属于代码，不是执行证据；必须把夹具源码、实际运行日志和独立账本观察分开。

逐 profile 的生命周期、生产链与证据层级见[派生能力矩阵](../../CAPABILITY-MATRIX.md)。可用源码、生成接线、目标编译、行为验证和最终批准不是同一声明。

## 结构与命名

独立模拟器进程、fixture、source与日志/运行数据分开；源码可跟踪，旧journal/凭据不是可随包发的测试输入。

类型使用UpperCamelCase，成员使用lowerCamelCase；数据库、protobuf和稳定业务ID分别遵循各自合同。描述目标命名不授权改写现有wire名称、PID或冻结载体。

## 依赖与装配

host通过正常connector/port调用，查询不制造完成；外部证据独立于宿主JVM生命周期。

## 回锚与更新

有业务知识输入的产物关联相应展开节点与最终源码位置；共享机制只关联其技术合同，不伪造业务来源。BC历史inline注释和JS外置同图映射分开解释；本批不恢复JS新增inline @knowledge。手写映射只是显式实现关系，不自动证明语义或精确span。

## 验证

重复请求、ACK丢失、独立账本/重启、冲突与readonly查询；不把mock通过称真实TA验收。 文档覆盖、代码编译与业务运行是不同证据；只有实际执行对应检查才可以报告通过。

## 版本与实例

本页按上述 profile 区分当前原生、保留/退役路径与手写参考；不跨 profile 传播实现或验收结论。完整来源 revision、摘要和生产链由目录、派生矩阵及 `sources.lock.json` 记录，本页不另抄暂定统计。
