# MODELS interface requests (implementation, not qualification)

The producer consumes only the eight frozen products. Main owns public schemas/compilers/scaffold and must approve/implement these additions; no reference/runtime files are changed here.

1. `workflow.technical` is needed in the host payload for stable operation identity. Proposed exact shape: `{stepId:"execute", codecVersion:"batch-codec-1", connectorPrefix, connectorVersion, ledgerEpoch, proofFormat}`. `proofFormat` is explicitly `digest-proof-v1` for the reference shape or `owner-certificates-v1` when Carry is used. Carry additionally requires `carry:{reservationSuffix,ownerSuffix}` (both nonempty, appended to the original manifest reservation/operation IDs). Per-owner certificates are necessary because R2 releases incoming carried grants using their original owner keys, not the current operation key. Owner-certificate bytes use digest + newline + sorted base64(owner):base64(certificate) rows, validated against the entire original manifest owner set. Prefix includes any intended separator. Every area operation uses prefix + authored area.id, never a Scala name. The current `compileWorkflows` output has no technical data, so generation will reject its absence rather than invent inventory/* or ledger epochs. A separately bound technical row attached by compileSagaMonarchHosts is sufficient.
2. `technical.wire` currently has explicit codec pins/tags and a format discriminator but not field order. This producer treats `length-prefixed-v1` as the finite frozen ABI: request uses host slot order; Saga/phase/item/association/receipt/result/manifest fields use REFERENCE-CONTRACT's explicit v1 order. It does not infer wire order from Scala names. Manifest count bound derives from maximum authored area batch size, not reference's constant 2. A format change needs a new explicit version.
3. Result payload must be a real declared nominal record with transaction id and original request fields. Current completion lower only understands txid/args/receipt-field. To represent originalRequest without fabrication it needs `source:{kind:"request"}` and a corresponding compiler-validated author reference (proposed `args`). All five completion mappings must map this record completely and identically. No receipt-sourced or silently omitted completion data is admitted by this finite ABI.
4. Nominal Quantity must remain positive Int rather than generic Long. ID and quantity Saga binding types must have canonical nominal aliases in reference-layout; role-based storage comes from Saga binding kind/bounds. The generated request field names follow host.slots exactly. Any nominal mismatch is an admission error, not a fabricated five-field inventory model.
5. The finite external provider ABI is `provider.ports: ApplicationPorts` (as the reference fixture). Root selects each role from its declared provider's `.ports`, with participant providing both warehouseA/warehouseB. Constructors consume exact ordered explicit technical groups using inputs directory/resourceA/resourceB/recoveryAuthorization/executionContext. No default constructors. If independent provider member selection is required, technical binding needs an explicit accessor field; currently generation uses only the frozen `.ports` ABI.
6. `run` area action needs an explicitly injected `Map[String, ExternalOperationPort]` for the selected managed run connector, validated against its selected execution operation pins. Standalone RunFactories/CheckedRunFacade use versioned public runtime directly; application business orchestration remains typed generated code, not an executeBusiness callback. Pure standalone run step interpreters are explicitly caller-owned.

7. The fixed C/SUBSET-RETRY case cannot be authored with one uniform terminal disposition per area. Proposed finite author union: `completion.terminal = {kind:"by-result", cases:[{result:"succeeded",disposition:{kind,target,compatibilityKey,delayMillis}},{result:"rejected-before-effects",disposition:{...}},{result:"compensated",disposition:{...}}]}`. All three terminals occur exactly once; unknown remains held. Existing ordinary terminal objects keep their semantics. The generator model/template includes this union, but MAIN must add schema/compiler validation before public compilation admits it. Mixed dispositions are rejected for Carry/retainCarried unless all branches route to the exact same target/key/delay and the downstream batch can hold every member. This is a field proposal, not an already-supported public compiler capability.

Capture declarations are exactly `{id,version,module,role,symbol,construction,implements,sourceRootKey,file,source,sourceRoot}`; constructors/provides never leak into capture metadata. `resolveSagaMonarchTarget({products,options})` (also accepts `{compilation,options}`) returns `{sourceRoots,handwritten}` directly for pre-capture use; `buildModels` includes the same object as `.lowered`. The pure pre-capture selector is not compilation evidence. Public generate independently replays the caller compilation through planProductSet.

Build resolver override: JVM property `truthsrc.repositories`, comma-separated repository URLs; no machine paths or downloads performed by this producer. Fixed runtime coordinates/hashes remain in model metadata and build comments; external directories derive exclusively from live implementationBuildInputs.
