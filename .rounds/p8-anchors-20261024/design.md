> 上轮验收结论：链路全通；缺口=BC 生成的 Scala 源码无锚落点；MCP 侧有 graphstore 未接线

## 一、目标

## 二、关键现场事实（2026-10-24 勘探，truthsrc@c34b2db / BC@9ec0f016）

- 锚索引格式（src/core/anchors.mjs）：`truthsrc.anchors/v1`，顶层
  `{version, anchors:{[key]:[location...]} }`；location =
  `{repo,file,module,symbol,span,generator,generatorVersion,fingerprint,status,verification}`；
  身份去重六元组 `(generator,repo,module,file,symbol,span)`；status ∈
  {planned,source-verified,stale,unmapped}；fingerprint=`sha256:<64hex>`；
  source-verified 判定=写后/查询时对实际字节 SHA256。
- core apply 的 location.repo = `resolve(outDir)` 绝对路径（不可配）；
  `queryAnchorsIndex(knowledgeKey,{indexFile,repoRoots})` 单索引文件；repoRoots
  键=location.repo 记录串、值=本地绝对根（本身即跨机重映射表）+ realpath/symlink
  拒穿越 + 三态判定（source-verified/stale/unmapped，planned 透传不升级）。
- digest 纪律：ir.digest（lib/saga/compile.mjs:566，输入 {schemaVersion,workshop,
  readiness,sagas}）与 definitionDigest（lib/saga/runtime-binding.mjs:293，输入
  严格 definition/binding/runtimeBinding-pin）均不含 anchors/knowledgeId——
  加锚零 digest 抖动，双钉点 ba60f58a / 3a586c81 测试钉死。
- BC 发射漏斗：所有生成文件过 `CQRSApplicationGenerator.writeArtifact`
  （CQRSApplicationGenerator.scala:286-336），strict saga 归属
  `ArtifactAttribution("strict-saga-module"|"strict-fixture-host", sagaId, "saga", families)`；
  文件头指纹 `// @generated by CodegenMain:<GeneratorVersion.value>`；definitionDigest
  落 SagaModule.scala `val DefinitionDigest`（StrictSagaModuleTemplate.scala:187）；
  StrictSagaExecutionMetadata 第 4 字段即 definitionDigest（SagaIrAdapter:445-449 复核）。
  BC 无 knowledgeId 概念（同义 noteId）；saga-core strict runtime 无 anchor/knowledgeId。
- BC 元数据先例：output 根恒写 knowledge-release.json（CodegenMain:214）——锚索引
  同层同惯例。scaffold 整拷与手写领地不经 writeArtifact 漏斗。
- MCP：mcp/server.mjs graphFor 只有 canonical/tree 两分支（:35-39）；除 diff 外
  tools/call 恒先 graphFor（:172-173）；anchors 工具 schema 已有 indexFile/repoRoots
  可选参数但描述仍是落地前文案（:70）。
- graphstore：graphFromStore 返回 buildGraph 全形状（verb 全兼容）；模块加载时
  Node<22.5 抛清晰错误。

## 三、设计决策（三定案）

### D1. 双索引所有权模型（不合并文件）
truthsrc core apply 与 BC 生成器各写各的 `anchors.json`；查询层做联合。
理由：各管线拥有自己的索引（无跨仓写）、无派生合并态（合并会产生第二个权威）、
身份六元组含 repo+file 天然跨索引不冲突。格式权威=metarch-truthsrc 仓；BC 产
`truthsrc.anchors/v1` 与既有跨仓格式先例（BC 消费 truthsrc.saga-runtime-contract/v3）
同型，双侧行为测试互钉。

### D2. BC 发射点=writeArtifact 单一漏斗，恒发不设 flag
- writeArtifact 成功写盘后 `attribution.schemaCategory == "saga"` 即记声明
  `{knowledgeKey:"saga:"+schemaNode, file:相对路径}`——fixture-host 家族与 P5 验证
  spec 只要带 saga 归属自动覆盖，未来新 saga 工件自动入锚。
- 生成收尾（CodegenMain.run 的 KnowledgeRelease.writeManifest 附近）：有声明才写
  `<outputRoot>/anchors.json`。对齐 knowledge-release.json 恒写惯例；无 saga 产物
  零文件零变化（非 saga 生成路径字节不变）。
- location 字段：repo=outputRoot 绝对路径、file 相对、module/symbol/span=null、
  generator='codegen-main'、generatorVersion=GeneratorVersion.value、
  fingerprint='sha256:'+写后重读实际字节哈希（write-then-verify，与 truthsrc core
  apply 同一契约）、status='source-verified'、verification={method:'sha256-bytes',
  level:'file',fileVerified:true,symbolVerified:false,spanVerified:false}、
  definitionDigest（sagaId→digest 侧表取自 StrictSagaExecutionMetadata 第 4 字段，
  不扩 ArtifactAttribution/ledger 行结构）。
- 原子写 temp+rename、key 排序；不合并 prior 索引——单写者每轮全量重发，删除的
  文件不残留。单/多项目模式都发（相对路径自然不同）。

### D3. 查询联合 + MCP 接线（全在 truthsrc）
- `queryAnchorsIndex` 的 indexFile 扩 string|string[]（内部归一）；逐索引各自过
  version 门与身份去重，同 key locations 拼接后六元组去重；任一索引缺失/坏版本
  fail-closed 抛错。聚合状态规则不变（任一 source-verified→source-verified）。
  格式小扩（文档化）：location 可选字段 definitionDigest（消费端透传不断言）。
- MCP：SOURCE_PROPS 增 `store`（惰性动态 import graphstore——Node<22.5 仅在使用
  store 时报清晰错误，基线 Node≥18 不破；handle 改 async）；anchors 工具
  indexFile schema 改 anyOf(string|string[])；描述修正为已落地语义。
- 零改动面：lib/query.mjs anchors 动词纯透传；graphstore 本体；core apply 侧
  （truthsrc 自产索引不加 definitionDigest——js 契约已有 inputDigest=ir.digest）。

## 五、红线（延续全部既往纪律）
不 push/tag/publish；不写共享 ingested-app/metarch-app；不启停共享服务、不占
9000/2551；ps 只 pid/comm；生成应用修复必须走 generator 合法源面重新生成；
`--direct --dry-run` 禁止组合；用 -Dcodegen.generatorVersion（非 versionPin）、
codegen.noGit=true；诚实标记不得因验证绿改写；树原子零改动⇒digest 零抖；隔离缓存
不入库（boot/ivy/sbt-global 留 untracked）；truthsrc 零 npm 依赖（node:sqlite 内建
合规）；测试集合重叠不相加；BC 构建用隔离 sbt global、禁自定义 -Djava.io.tmpdir。

## 六、边界（本批之外，如实登记）
- BC 推图侧 saga 节点 id 形状（application.services.transactor.*）与 truthsrc
  kind:id 寻址不统一——锚通道即跨管线对接面，图 id 统一另立批。
- truthsrc core apply 自产索引不发射 definitionDigest（js 契约已有 inputDigest）。
- 部署面（event-stream source/物理多 JVM+共享耐久 journal）、run-all 金样管线、
  strict-scala 封禁、golden master（不含 strict 件）均不动。
- saga-core 零改动。
